# Roadmap — Marcos Freitas Developer Hub

## Fase 0 — Fundação (0–2 meses)
- Definir identidade textual e posicionamento
- Estrutura inicial do site (Home, Projetos, Blog, Contato)
- Templates de README e posts
- Primeiro projeto técnico simples publicado

## Fase 1 — Portfólio Vivo (3–6 meses)
- Site no ar com layout moderno
- Blog com posts técnicos recorrentes
- 2 projetos open source bem documentados
- Integração básica frontend + backend
- Uso inicial de IA em features específicas

## Fase 2 — IA Aplicada (7–12 meses)
- Projeto flagship com foco em IA
- Casos reais de uso (automação, suporte, QA, devtools)
- Estratégia clara de testes para sistemas com IA
- Posts técnicos sobre arquitetura e trade-offs
- Evolução para frontend mais avançado (React)

## Fase 3 — Consolidação (13–18 meses)
- Refinamento dos projetos
- Melhor arquitetura e separação de camadas
- Suporte a múltiplas stacks/bancos quando aplicável
- Primeiros experimentos de monetização

## Fase 4 — Produto e Autoridade (19–24 meses)
- Projeto(s) com usuários reais
- Monetização ativa (serviço, hosted, template ou suporte)
- Portfólio consolidado
- Forte presença técnica no GitHub e LinkedIn
