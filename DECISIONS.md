# Registro de Decisões — Marcos Freitas Developer Hub

## Decisões Iniciais

- O produto principal é o próprio desenvolvedor (portfólio vivo)
- Foco em desenvolvimento Fullstack
- Conteúdo técnico em PT-BR
- Uso de IA como ferramenta de apoio, não como atalho
- Experiência em QA é um diferencial estratégico
- Não usar imagem pessoal em vídeos
- Construção de projetos open source com potencial de monetização
- Horizonte de construção: 2 anos

## Arquitetura de Aprendizado

- Aprender múltiplas stacks dentro de um único ecossistema
- Frontend evolui de JS puro para React
- Backend pode ter múltiplas implementações
- Bancos de dados entram conforme necessidade real
- Cada decisão técnica deve ser documentada

## Comunicação

- Linguagem clara, técnica e objetiva
- Sem hype vazio
- Mostrar erros, aprendizados e evolução
